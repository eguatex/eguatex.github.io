# Código de conduta

O ÉguaTex nasceu na Amazônia para aproximar o LaTeX de quem escreve. Queremos que qualquer pessoa se sinta bem-vinda aqui, independentemente de origem, idade, gênero, identidade, orientação, deficiência, aparência, religião, nível de experiência ou região onde vive.

## O que esperamos

- Tratar todo mundo com respeito e paciência, principalmente quem está começando.
- Criticar ideias e código, nunca pessoas.
- Aceitar opiniões diferentes e explicar as próprias com calma.
- Reconhecer o trabalho de quem ajudou.

## O que não aceitamos

- Ofensas, piadas preconceituosas, ameaças ou assédio de qualquer tipo.
- Expor dados pessoais de alguém sem permissão.
- Insistir em contato com quem pediu para parar.

## Se algo acontecer

Escreva para **contatoeguatex@gmail.com**. A mensagem é lida pela equipe e tratada com discrição. Quem não seguir este código pode ter comentários removidos ou ser impedido de participar do projeto.
