## Sobre

Este é o repositório do site oficial do ÉguaTex, editor LaTeX gratuito e offline, feito na Amazônia.

O site apresenta o app, ensina a instalar e reúne uma galeria de modelos LaTeX em domínio público. Ele é publicado pelo GitHub Pages no endereço www.eguatex.com.br.

## O que tem aqui

| Pasta ou arquivo | Conteúdo |
| --- | --- |
| `*.html` | Páginas do site |
| `assets/` | Estilos, scripts e imagens |
| `modelos/` | Modelos LaTeX da galeria, com código-fonte, PDF e prévias |
| `ferramentas/` | Gerador que compila os modelos e monta a galeria |
| `IDENTIDADE.md` | Textos oficiais do ÉguaTex (lema, descrição curta e selo) |
